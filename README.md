# Paperplane

Paperplane is a mobile-first, browser-based photo editor inspired by the fast, expressive editing flow of social photo apps.

## Features

- Upload an image or use the device camera
- Mobile-first, app-like editor UI
- Crop/zoom-friendly canvas workspace
- Add text overlays
- Add emoji and sticker-style overlays
- Move and remove overlays
- Export the edited image as PNG
- Automatic Paperplane watermark on exported images
- No account or backend required
- Installable as a Progressive Web App on supported browsers

## Run locally

Paperplane is a static web app. Open `index.html` through a local web server or deploy the repository to GitHub Pages.

For GitHub Pages, enable **Settings → Pages → Deploy from a branch** and select the branch containing the app.

## Privacy

Images are processed in the browser. Paperplane does not upload photos to a server.
