# Code of Conduct

## Our standard

Participants in the Paperplane project are expected to be respectful, constructive, and professional. Harassment, discrimination, personal attacks, intimidation, and deliberately disruptive behavior are not acceptable.

## Scope

This code applies to project spaces, pull requests, issues, discussions, and other project-related interactions.

## Enforcement

Report unacceptable behavior privately to the project maintainers through the contact method listed in the repository profile. Reports will be reviewed and handled as appropriate.
