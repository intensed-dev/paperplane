# Contributing to Paperplane

Thanks for contributing to Paperplane.

## Development

Paperplane is intentionally lightweight and browser-based. Keep the app dependency-light and make sure features work well on mobile screens and touch input.

## Pull requests

1. Fork or create a feature branch.
2. Make focused changes.
3. Test the app on a mobile-sized viewport and a desktop browser.
4. Check that images remain local and are never uploaded unintentionally.
5. Open a pull request with a concise description of the change.

## Code style

Prefer readable vanilla HTML, CSS, and JavaScript. Avoid unnecessary frameworks or build tooling for small changes.

## Reporting bugs

Include the browser/device, reproduction steps, expected behavior, and actual behavior. Do not attach private photos or other sensitive data.
